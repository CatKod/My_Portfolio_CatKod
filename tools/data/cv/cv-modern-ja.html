現在
APES Lab / 組み込みファームウェアエンジニア - EV 充電設備

パートナー企業と共同開発した商用 EV 充電設備の開発に参加しています。ソースコードは NDA の対象のため、以下は実装コードではなく、自身が担当した設計・実装範囲の説明です。

  • リングトポロジの EV 充電ネットワーク向け電力配分ファームウェア - STM32H723、CAN 2.0B 29ビット、SPI 変換の MCP2515 経由で 16 キャビネット、最大 32 口の充電ガンに対応。
  • 自律分散型電力融通アルゴリズム - 待機中（アイドル）の充電ガンから電力を自律融通し、充電需要発生時にフェイルセーフに回収。
  • 4層アーキテクチャ：アプリケーション -> ミドルウェア（サービス / FSM / 制御）-> ドライバ -> HAL。上位層への呼び出し方向を厳格に制限。
  • MISRA C:2012 の静的解析パイプライン（カスタムアドオン付き cppcheck）およびモック HAL を用いた PC 上の単体テスト。
  • ノンブロッキング設計 - 制御パスにおける HAL_Delay() を完全に排除。すべてのタイミングは 1 ms のソフトウェアタイマー配列から取得。
  • 2ポート出力 EV 急速充電器ファームウェア - OCPP、GB/T 27930 による車両側通信、DLT-645 による DC 電力量計量、WIZnet イーサネットコントローラ、RFID、絶縁監視、FATFS 併用 USB Host、bootloader / IAP。

embedded-iot-toolkit オープンソース - MIT - 単体テスト 89 項目

依存関係ゼロの C99 ライブラリ。繰り返し実装しているファームウェアの基本部品を集約しました：ノンブロッキングタイマーバンク、チェックサムと同期回復を備えた ISR セーフなフレーミングシリアルプロトコル、ビットタイミング算出器つき CAN 2.0B 29ビット codec、そして古い値を返さず鮮度不足を報告するセンサデコーダ。

github.com/CatKod/embedded-iot-toolkit
rokid-max-diy-station オープンソース - MIT - 単体テスト 218 項目

Rokid Max AR グラスを空間ディスプレイに。仮想の Windows モニターが視野に貼り付くのではなく、部屋の中に実在する形です。USB HID の IMU を Mahony フィルタで 3 自由度の姿勢に融合し、IddCx ドライバが実在するモニターを生成、Windows.Graphics.Capture と D3D11 がそのデスクトップを 3D クアッドとして再投影します。

github.com/CatKod/rokid-max-diy-station
SmartHome 大学開発プロジェクト - 最高評価 10/10

リアルタイム MCU が安全性の面でクラウドに依存しない 2 層アーキテクチャ。ESP32-S3 が Wi-Fi と MQTT を担当し、STM32H7 がハードウェアを掌握します。RFID と PIN 入力、シフトレジスタによる LED バス、環境センサ、窓の自動アクチュエータを備えています。

github.com/CatKod/SmartHome
Smart Power Outlet 卒業研究 - 単独開発

ボード一枚ではなく製品として完結した IoT デバイス：PCB は EasyEDA Pro で設計し、ファームウェアは Wi-Fi プロビジョニング付きの ESP-IDF で認証情報（SSID・パスワード）をハードコードせず、PlatformIO のビルドが ESP32 と ESP8266 の両方に対応し、クロスプラットフォームの Flutter アプリが操作します。

github.com/CatKod/Smart_Power_Outlet
