APES Lab | Present
Embedded Firmware Engineer - EV Charging Station

Contribute to a commercial EV charging station developed with a partner manufacturer. The code is under NDA, so the scope below describes my responsibilities rather than the implementation.

  • Power-sharing firmware for a ring-topology EV charging network - STM32H723, CAN 2.0B 29-bit over SPI-to-CAN MCP2515, up to 32 charging guns across 16 cabinets.
  • Distributed power borrowing and reclaim algorithms - the firmware autonomously borrows capacity from idle guns and reclaims it later.
  • Four-layer architecture: Application -> Middleware (Service / FSM / Control) -> Driver -> HAL, with strictly enforced upward-only calls.
  • MISRA C:2012 static analysis pipeline (cppcheck with a custom addon) and PC-based unit tests with a mocked HAL.
  • Non-blocking firmware design - no HAL_Delay() anywhere; all timing comes from a 1 ms software timer array.
  • Two-gun EV charger firmware - OCPP, GB/T 27930 vehicle-side comms, DLT-645 DC metering, WIZnet Ethernet controllers, RFID, insulation monitoring, USB Host with FATFS, bootloader / IAP.

PROJECTS

embedded-iot-toolkit Open source - MIT - 89 tests

A dependency-free C99 library of the firmware building blocks I keep rewriting: a non-blocking timer bank, an ISR-safe framed serial protocol with checksums and resynchronisation, a CAN 2.0B 29-bit codec with a bit-timing solver, and sensor decoders that report staleness instead of returning a stale value.

github.com/CatKod/embedded-iot-toolkit

rokid-max-diy-station Open source - MIT - 218 tests

Rokid Max AR glasses turned into a spatial display: a virtual Windows monitor that lives in the room, not glued to your eyes. The IMU is read over USB HID and fused by a Mahony filter into a 3-DoF head pose, an IddCx driver creates a genuine monitor at negative coordinates so the OS owns hit-testing and focus, and Windows.Graphics.Capture plus Direct3D 11 re-project that desktop as a 3D-anchored quad on the Micro-OLED.

github.com/CatKod/rokid-max-diy-station

SmartHome University capstone - 10/10

A two-tier architecture where the real-time MCU never depends on the cloud for safety. The ESP32-S3 handles Wi-Fi and MQTT; the STM32H7 owns the hardware. RFID and PIN entry, a shift-register LED bus, environmental sensors and an automatic window actuator.

github.com/CatKod/SmartHome

Smart Power Outlet Graduation capstone - solo

A complete IoT product rather than a board: the PCB was designed in EasyEDA Pro, the firmware is ESP-IDF with Wi-Fi provisioning so no credential is ever hardcoded, a PlatformIO build covers both ESP32 and ESP8266, and a cross-platform Flutter app drives it.

github.com/CatKod/Smart_Power_Outlet

Sun-Car Damage Assessment SUN scholarship project

A computer vision pipeline for object detection, instance segmentation and severity scoring, built to apply for a SUN scholarship. An ESP32-CAM captures frames and streams the result to an STM32 over UART, so inference sits on the edge rather than in the cloud.
